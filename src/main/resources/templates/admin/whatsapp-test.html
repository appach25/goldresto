Instructions
  1. Ajoutez votre Auth Token dans application.properties :
    twilio.authToken=VOTRE_AUTH_TOKEN
  2. Vérifiez la configuration avec le bouton ci-dessus
  3. Sélectionnez un client qui a un numéro de téléphone
  4. Envoyez un message de test pour vérifier que tout fonctionne
Important : Le numéro WhatsApp doit être au format international (ex: +33612345678 pour la France)
